# Case-study UI concept

Review URL: https://case-study-ui-preview.portfoliov2-9ks.pages.dev

This isolated, non-indexable preview demonstrates a project list and separate
Trakio and Voy Travel pages. It reuses the current palette, typography, actual
project descriptions, screenshots, and links. The layouts work on mobile and
desktop and include a theme toggle.

These files are outside Astro's production routes and preserve the UI concept
that the user approved. The production implementation now uses real localized
routes at `/{lang}/projects/{slug}/` for all seven projects.

The preview uses existing project descriptions, without invented metrics or
business outcomes. More detailed case-study writing can follow UI approval.
